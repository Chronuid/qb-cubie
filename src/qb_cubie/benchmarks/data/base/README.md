# base-v1 development dataset

24 review cases and four independent project designs with three episodes each.
All material is public and potentially known. References are author_checked;
no human admission is claimed. Maintainability cases require manual judgment.

Use cubie-bench validate PATH --check-references before experiments. Structure-only
validation executes no candidate code. Reference checks execute trusted Python.
The reference matcher checks structured findings; it is not a semantic judge.
